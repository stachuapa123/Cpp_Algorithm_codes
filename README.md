# 🖥️ C/C++ Algorithms & Games Portfolio

A curated portfolio showcasing various algorithms, data structures, and interactive games implemented in C and C++.

## ⚙️ Algorithms & Data Structures

* **[Stack Processor](./Low_Level_Algorithms/StackProcessor.cpp):** A CPU instruction simulator (e.g., addition operations) implemented uniquely *without* the use of loops.
* **[Dijkstra's Algorithm](./Low_Level_Algorithms/DijkstraBoard.cpp):** A custom implementation of the classic pathfinding algorithm, featuring advanced mechanics like route waiting times.
* **[Sparse Table](./Low_Level_Algorithms/SparseTable.cpp):** A highly optimized data structure designed for searching and modifying data efficiently with **O(log n)** time complexity.
* **[Market Lamps](./Low_Level_Algorithms/MarketLamps.cpp):** An algorithmic approach to visualizing stock price data using a "market lamps" representation.

## 🎮 Console Games

* **[Frogger](./Console_Games/Frogger.cpp):** A console-based adaptation of the classic arcade game where the player guides a frog safely across a hazardous river.
* **[BlackBox](./Console_Games/BlackBox.cpp):** A custom implementation of the classic deductive logic puzzle, inspired by the [original BlackBox game](https://apps.microsoft.com/detail/9wzdncrfk15d?hl=pl-PL&gl=PL).

## 🐍 SDL Snake

A modernized version of the classic Snake game built using the **SDL library**. It features frame-rate independent speed regulation (delta-time) to ensure consistent gameplay across all computers, regardless of hardware performance.

### 🚀 How to Run
To launch the SDL Snake project, simply open the provided [`snake.sln`](./Snake_SDL/snake.sln) (Visual Studio Solution) file in your IDE and build the project.
